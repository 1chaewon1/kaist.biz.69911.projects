## How to update your row

One member of each team updates the row of the team with a pull request: you propose a change, and the course staff merges it.
The row number is your team number.

### In the browser

1. Open [this file on github.com](https://github.com/yijisoo/kaist.biz.69911.projects/blob/main/2026-fall/PROJECTS.md) and select the pencil icon (Edit this file).
2. GitHub says that you need a fork to propose changes.
   Select "Fork this repository".
3. Find the row with your team number and replace its placeholder cells.
   Copy the row format below.
4. Select "Commit changes…", write a short message such as `Update Team 3 project`, and select "Propose changes".
5. Select "Create pull request" on each of the next two screens.
6. The course staff reviews and merges the pull request.
   Your row then shows on this page.

Row format:

```
| 3 | Project Name | One sentence: who it is for and what it does. | [your-app.vercel.app](https://your-app.vercel.app) | [your-username/your-repo](https://github.com/your-username/your-repo) |
```

### With your coding assistant

Paste this prompt into your coding assistant (Claude Code, for example) and fill in the values:

> "Fork https://github.com/yijisoo/kaist.biz.69911.projects and update the row for Team ___ in 2026-fall/PROJECTS.md. Project name: ___. Description: ___. Repository: https://github.com/___/___. Change only that one row, then open a pull request to the original repository. I am new to git, so explain each step before you run it."

### Rules

* Change only the row of your team, and keep its number.
* Write the description in one sentence, in Korean or English.
* Leave `—` in the Live column until the product has a public address.
* If your repository is private, write `private` in the Repositories column with no link.
* Keep the row on one line, and do not use the `|` character inside a cell.
* When the project name, the live address, or the repository changes, edit the same row with a new pull request.
